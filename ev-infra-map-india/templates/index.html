Methodology and limitations

Data handling

Station records, EV registrations and state charging totals are stored separately. Nothing is estimated: a missing value stays empty and is displayed as unavailable. District is never inferred from a city name or coordinates.

Station records

Source rows list one connector each. Rows with the same state, name and coordinates are merged into a single station; the number of rows becomes the connector count and the highest listed power is kept. State names with obvious typos or spacing (for example “Keral”) are corrected to the official name and the count of corrections is logged. Rows without a recognisable state or valid India coordinates are skipped and reported.

Planning calculation

Target units = ceiling(EV count ÷ EVs per charging unit). Estimated extra units = max(0, target − existing units in the district). It is calculated only for districts with a verified EV count. The default ratio of 100 is a demonstration assumption, not an official standard.

Interpretation

Results are screening aids, not site recommendations. Validate station status, connector counts, land, grid capacity and road access locally before any decision. The mapped stations are a sample, so absence of a marker does not mean absence of a station.
